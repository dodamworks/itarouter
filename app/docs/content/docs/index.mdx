ItaRouter provides a single API entry point for multiple AI models. Your ItaRouter key identifies your account; you do not need to configure provider channels.

<Callout title="Launch preparation">
Model requests and paid top-ups are not available yet. You can explore the console and create keys, but creating a key does not add credit or enable model access.
</Callout>

## Create your account

Open the ItaRouter website and choose **Create account**. Complete email verification, then sign in to the console.

## Create an API key

Open **Console → API keys**. Create a separate key for each app and keep it on your server. [Read the key guide](/docs/api-keys).

## Choose a model

The **Models** page is the source of available model IDs, supported features, and prices. Once model access opens, choose a listed model and check your wallet balance before sending requests. [Explore model selection](/docs/models).

## Connect and monitor

Set your client's base URL and ItaRouter key. Start with a small request, then review **Usage logs** and **Wallet**. [See the request example](/docs/api).
