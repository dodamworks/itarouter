## ItaRouter source

ItaRouter is based on [New API](https://github.com/QuantumNous/new-api). The modified product source is available in the [ItaRouter repository](https://github.com/dodamworks/itarouter), with its AGPL licence and notices. A local preview can include changes that have not been published yet.

Frontend design and development by New API contributors.

## Documentation tooling

This documentation site uses [Fumadocs](https://github.com/fuma-nama/fumadocs), whose packages include their MIT licence notices. Fonts are self-hosted Geist Sans and Geist Mono; their licence files are included with the site assets.

## What these docs cover

These are customer guides, not an administrator deployment manual. Only documented and enabled ItaRouter features should be treated as available services.

## Documentation basis

The endpoint reference is generated from a reviewed subset of the bundled [relay specification](https://github.com/dodamworks/itarouter/blob/main/app/new-api/docs/openapi/relay.json). Key settings, access checks, usage fields and billing descriptions are checked against the corresponding product source. Administrator management APIs are outside this customer guide.

See the [upstream user documentation](https://docs.newapi.pro/en/docs) for the original project's deployment and administration guides. Those guides describe New API capabilities; they do not establish ItaRouter's live model inventory, payment methods, or operating policies.
