Supply `model`, `messages`, and `max_tokens`, plus the `anthropic-version` header. Use your ItaRouter key through `x-api-key` or Bearer authentication. System instructions use the top-level `system` field. This format alone does not make every model Claude-compatible.

These fields are generated from the bundled relay specification. Model access is in preparation; this page is a request-format reference, not a successful live request.
